التخزين ✕

البيانات محفوظة دائماً بشكل آمن داخل متصفحك على هذا الجهاز (localStorage) — لا تُرسل لأي سيرفر خارجي. بالإضافة لذلك عندك خياران لملف إكسل حقيقي على اللابتوب:

خيار إضافي للابتوب فقط — ربط مباشر بملف إكسل محلي (لا يعمل على الموبايل):
يفتح/ينشئ ملف .xlsx حقيقي على جهازك، ويحفظ فيه تلقائياً بعد كل عملية. يعمل فقط على Chrome أو Edge، وبشرط فتح الصفحة عبر خادم محلي وليس بفتح الملف مباشرة (لأن المتصفح يمنع هذه الميزة على ملفات file://).
شغّل من الطرفية داخل مجلد الملف: python -m http.server 8000 ثم افتح http://localhost:8000/index2.html بمتصفح كروم.
Google Sheets — يشتغل من أي جهاز (لابتوب أو موبايل) بعد الإعداد لمرة وحدة:
لازم يكون التطبيق مستضاف على رابط حقيقي (https) وليس ملفاً مفتوحاً مباشرة — الأسهل: استضافة مجانية على GitHub Pages. الخطوات بالترتيب:
  1. ارفع ملف التطبيق لمستودع GitHub جديد (باسم index.html)، وفعّل GitHub Pages من إعدادات المستودع — رح ياخد رابط دائم متل https://username.github.io/repo
  2. افتح console.cloud.google.com وأنشئ مشروعاً جديداً (مجاني)
  3. فعّل Google Sheets API من قسم Library
  4. من OAuth consent screen اختر External، واملأ الحقول الأساسية، وضيف إيميلك تحت Test users
  5. من Credentials أنشئ OAuth Client ID نوع Web application، وضيف رابط GitHub Pages تبعك (بدون أي مسار، فقط مثل https://username.github.io) تحت Authorized JavaScript origins
  6. افتح sheets.new لإنشاء شيت فارغ، وانسخ الرقم الطويل من الرابط بين /d/ و /edit
  7. عبّي الحقلين تحت، أو — للربط الدائم من كل جهاز بدون إعادة كتابة — اطلب مني أحطهم مباشرة بكود الملف قبل ما ترفعه
